PFO2 - Sistema de Gestión de Tareas

API RESTful + Cliente en Consola · Seguridad · SQLite · Python

Descripción General

Este proyecto implementa una arquitectura cliente-servidor profesional, enfocada en la gestión segura de usuarios y tareas. La API está desarrollada en Flask siguiendo buenas prácticas REST y el cliente en consola permite interactuar fácilmente desde terminal. Ideal para afianzar conceptos de autenticación, persistencia y separación de responsabilidades.

Características Técnicas

  • API RESTful con endpoints bien definidos (/registro, /login, /tareas).
  • Autenticación robusta y hash de contraseñas con Werkzeug.
  • Persistencia eficiente y portable con SQLite.
  • Cliente en consola multiplataforma para pruebas y automatización.
  • Código modular y fácilmente extensible.

Instalación y Puesta en Marcha

  1. Clona el repositorio y crea un entorno virtual: 
    git clone https://github.com/ing-castano/server-client-model-app.git
cd server-client-model-app
python -m venv venv
# Windows: .\venv\Scripts\activate
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
  2. Inicializa la base de datos ejecutando una vez el servidor: 
    python servidor.py
  3. Inicia el cliente y explora las funcionalidades: 
    python cliente.py

Buenas Prácticas y Seguridad

¿Por qué hashear contraseñas?
Nunca almacenes contraseñas en texto plano. El uso de funciones como generate_password_hash de werkzeug.security garantiza seguridad ante filtraciones, usando algoritmos modernos como PBKDF2.
SQLite en proyectos académicos y prototipos:
  • No requiere configuración de servidor externo.
  • Portabilidad: solo un archivo, fácil de respaldar y migrar.
  • Compatible con SQL estándar y consultas complejas.
  • Ideal para proyectos educativos y pruebas rápidas.
