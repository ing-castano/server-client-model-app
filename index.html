Proyecto PFO2 - Sistema de Gestión de Tareas

Este proyecto consiste en una API desarrollada con Flask y una interfaz cliente en consola para gestionar usuarios y tareas. La base de datos utilizada es SQLite.

Requisitos

  • Python 3.10 o superior
  • Pip (instalador de paquetes de Python)
  • Sistema operativo Windows, Linux o macOS

Instalación

git clone https://github.com/ing-castano/server-client-model-app.git
cd server-client-model-app
python -m venv venv
# Activar entorno:
# En Windows:
.\venv\Scripts\activate
# En Linux/macOS:
source venv/bin/activate
pip install -r requirements.txt

Inicializar la base de datos

Ejecutar el servidor una vez para crear la base:

python servidor.py

Ejecutar el cliente

python cliente.py

Comandos útiles de SQLite

sqlite3 tareas_pfo2.db
.tables
.schema nombre_de_tabla
SELECT * FROM nombre_de_tabla;
.exit

¿Por qué hashear contraseñas?

Hashear contraseñas protege a los usuarios en caso de que la base de datos sea comprometida. Usamos la función generate_password_hash de werkzeug.security, que aplica un algoritmo seguro con salt integrado, dificultando ataques por diccionario o fuerza bruta.

Ventajas de usar SQLite

  • No requiere instalar ni configurar un servidor externo.
  • Almacena todos los datos en un único archivo portátil.
  • Ideal para proyectos chicos y educativos.
  • Se puede consultar fácilmente desde la terminal o Python.
