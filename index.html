Proyecto PFO2 - Sistema de Gestión de Tareas

GitHub Repo

https://github.com/ing-castano/server-client-model-app

Este proyecto consiste en una API desarrollada con Flask y una interfaz cliente en consola para gestionar usuarios y tareas. La base de datos utilizada es SQLite.

Requisitos

  • Python 3.10 o superior
  • Pip (instalador de paquetes de Python)
  • Sistema operativo Windows, Linux o macOS

Instalación

git clone https://github.com/ing-castano/server-client-model-app.git
cd server-client-model-app
python -m venv venv
# Activar entorno:
# En Windows:
.\venv\Scripts\activate
# En Linux/macOS:
source venv/bin/activate
pip install -r requirements.txt

Inicializar la base de datos

Ejecutar el servidor una vez para crear la base:

python servidor.py

Ejecutar el cliente

python cliente.py

Comandos útiles de SQLite

sqlite3 tareas_pfo2.db
.tables
.schema nombre_de_tabla
SELECT * FROM nombre_de_tabla;
.exit

¿Por qué hashear contraseñas?

Hashear contraseñas es fundamental para proteger la información sensible de los usuarios. Si se almacenaran contraseñas en texto plano, un atacante que acceda a la base de datos podría verlas directamente. En cambio, al aplicar un hash (función unidireccional), incluso si alguien roba la base, no podrá recuperar las contraseñas reales fácilmente.

Además, al usar un algoritmo como bcrypt, sha256 o similar (idealmente con un salt aleatorio), se evita que dos contraseñas iguales tengan el mismo resultado y se dificulta el uso de ataques por diccionario o fuerza bruta.

En nuestro proyecto utilizamos la librería werkzeug.security, incluida con Flask, que proporciona funciones como generate_password_hash y check_password_hash. Esta opción es simple, segura y práctica para proyectos educativos, ya que abstrae los detalles criptográficos y permite aplicar buenas prácticas con pocas líneas de código. Esta librería incorpora un “salt” aleatorio que “condimenta” el algoritmo de encriptación de la contraseña, resultando en credenciales más difíciles de vulnerar mediante métodos de fuerza bruta.

Ventajas de usar SQLite

  • No requiere servidor: la base se almacena en un solo archivo .db.
  • Fácil de usar: se puede consultar con comandos simples desde la terminal o desde Python.
  • Portabilidad: podés mover el archivo de base de datos fácilmente a otra computadora.
  • Buen rendimiento: para pocas conexiones simultáneas y volumen de datos moderado, funciona muy bien.
  • Integración directa con Python: el módulo sqlite3 viene incluido en la biblioteca estándar.
