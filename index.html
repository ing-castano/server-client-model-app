Sistema de Gestión de Tareas con API y Base de Datos (PFO 2)

Objetivos

  • Implementar una API REST con endpoints funcionales.
  • Utilizar autenticación básica con protección de contraseñas.
  • Gestionar datos persistentes con SQLite.
  • Construir un cliente en consola que interactúe con la API.

Servidor (API Flask)

El servidor ofrece los siguientes endpoints:

  • POST /registro: Registra usuarios con contraseñas hasheadas.
  • POST /login: Permite iniciar sesión verificando credenciales.
  • GET /tareas: Muestra esta página de bienvenida.

Los datos se almacenan de forma segura usando SQLite y WerkZeug para el hash de contraseñas.

Cliente en Consola

Desde el cliente en consola podrás registrar usuarios, iniciar sesión y consultar tus tareas.

Por qué hashear contraseñas?

Hashear contraseñas protege la información sensible. Nunca se almacenan en texto plano para evitar que si alguien accede a la base pueda leerlas fácilmente. Usamos Werkzeug, que incorpora un “salt” aleatorio para aumentar la seguridad y prevenir ataques por fuerza bruta.

Ventajas de SQLite en este proyecto

  • No requiere servidor externo, todo está en un archivo local.
  • Fácil de usar y portátil.
  • Ideal para proyectos pequeños y educativos.
  • Integración directa con Python sin configuraciones complejas.

Pruebas y Ejecución

Ejecuta el servidor con python servidor.py y luego corre el cliente con python cliente.py. Interactúa con el menú para registrar usuarios, iniciar sesión y ver tareas.
